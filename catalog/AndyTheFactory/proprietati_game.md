## README excerpt

> # Simple Monopoly-like Boardgame (Pygame)
> Run a small Monopoly-like boardgame implemented with Pygame.
> Game was drawn and invented by my 10 year old son, and I implemented it in Python as a fun project.
> Setup
> python3 -m pip install -r requirements.txt
> Run
> python3 main.py
> Notes
> - Board image should be at `assets/board.jpg` (already present).
> - Board and players are initialized from JSON in `assets/data/`.
